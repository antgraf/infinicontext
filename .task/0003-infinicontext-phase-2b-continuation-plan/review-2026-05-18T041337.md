### [warning] ScopeResolver repo-root containment check is vulnerable to prefix-match bypass
- Reviewers: security
- Location: `src/InfiniContext.Core/Review/ScopeResolver.cs:244-248`
- Why: Path-traversal bypass: `ScopeResolver` reads file contents and feeds them verbatim into reviewer prompts (egressed to Anthropic) and the persisted on-disk review report. A malformed `--scope` or progress.md `Files touched` entry can exfiltrate sibling-directory secrets.
- Fix applied (edit):
  Before:
  ```
              var full = Path.GetFullPath(Path.Combine(repoRoot, trimmed));
              if (!full.StartsWith(repoRoot, StringComparison.Ordinal))
              {
                  excluded.Add(new ExcludedFile(rel, "outside repo root"));
                  continue;
              }
  ```
  After:
  ```
              var full = Path.GetFullPath(Path.Combine(repoRoot, trimmed));
              if (!full.StartsWith(repoRoot + Path.DirectorySeparatorChar, StringComparison.Ordinal)
                  && !string.Equals(full, repoRoot, StringComparison.Ordinal))
              {
                  excluded.Add(new ExcludedFile(rel, "outside repo root"));
                  continue;
              }
  ```
- Reviewer confidence: 0.95
- Coordinator confidence: 0.92
- Coordinator note: Clean, local fix mirroring the already-correct pattern in AutoApplyExecutor. Reviewer confidence 0.95; the edit is small, surgical, and the equivalent pattern is already validated elsewhere in the same PR. Meets all auto_apply gates.
